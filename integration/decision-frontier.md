# High-level decision frontier

Generated by `npm run analyze` from 24 enabled packages for EU5 1.4.5.
The 367 unresolved deep findings are grouped into 67 system-level votes.
These cards ask what Concordia should preserve or use as its base. A vote does not itself alter files; it authorizes the subsequent merge and semantic-resolution records.

## Voting model

For each decision, choose one policy or describe a custom synthesis:

1. Preserve both systems through a semantic merge.
2. Use one package as the base and port named unique behavior from the others.
3. Prefer one package's implementation for this domain.
4. Accept coexistence only after the linked deep evidence proves it safe.
5. Exclude a conflicting subsystem or package from Concordia.

Reply in chat with a decision number and policy, for example: `Decision 3: use Imperial Ambitions as the base, but preserve the Rus successor-state names and events.`
